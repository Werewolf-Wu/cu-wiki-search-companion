## 升版前门禁

### 行为回归

- [ ] RC 同轮页面发生 `info -> revisions` 新 revision 竞态时，正常候选与游标仍原子提交，错配正文不落库，竞态页留下可恢复 pending job。
- [ ] RC 明确返回 missing 时不创建或复活页面；更旧/畸形正文响应仍使整轮失败且不推进游标。
- [ ] 正文搜索先完成排序与截断，只为最终 `limit` 条结果生成摘要；title boost 与稳定排序不变。
- [ ] NFKC、繁简、大小写与空白变化不会令摘要漂移为空或只剩省略号。
- [ ] 缺失或损坏的 syncState 不进入字符串拼接、NaN 或回退序列循环；关键游标损坏停止写入并可诊断。
- [ ] 缺 `local-sequence` 时，读取、刷新、检查和发布使用同一恢复值，防抖发布最终收敛。
- [ ] Wiki API 只重试瞬时失败、`maxlag` 与 `ratelimited`；永久性 4xx 立即失败。
- [ ] Lua 比较表达式不再成为返回键；Wikitext 实体只解码一层。
- [ ] AltGr/Ctrl+Alt 不触发 Alt+K；面板内任意控件聚焦时 Escape 均可关闭，IME 组合期间除外。
- [ ] 重叠 Data 规则保存各自执行并获得自己的结果；文件锁不可用与异步失败具有准确、可观察的错误。

### 一致性与性能

- [ ] facts、jobs、localSeq、RC/对账游标原子性与 transaction callback 后 abort 回归保持通过。
- [ ] content jobs 准备、进度与对账收尾在 500/2,000/10,000 条合成数据上保持线性操作量，不全量重写未变化 jobs。
- [ ] 维护诊断和队列修复不同时保留全部正文 payload；文件批次不反复重读完整文件表。
- [ ] 快照发布只做一次 UTF-8 编码；有效快照恢复只做一次完整 payload parse，紧随其后的 inspect 不重复解析。
- [ ] title/content/lua 的同步重建、异步重建、快照恢复与 tombstone 增量结果签名一致。
- [ ] 二字 CJK 不启用编辑距离 fuzzy；既有标题 exact/prefix/substring/繁简召回不退化。

## 真实浏览器验收

- [ ] 安装未升版候选后，编辑页冷启动 15 秒仍为 bootstrap；不读三类快照、不加载 jieba、不恢复正文/Lua/文件索引。
- [ ] 正文 benchmark 达到现有 150 ms p95 门槛，常见词输入无明显主线程停顿，摘要包含预期命中。
- [ ] 标题、正文、Lua、Data、文件五种模式签名与隔离保持一致。
- [ ] 完整正文缓存恢复不发 revisions 请求。
- [ ] 快照连续恢复与本地重建签名一致；恢复不慢于 10 秒且至少比本地重建快 30%。
- [ ] Alt+K、AltGr、Escape、IME、文件刷新和 Data 规则错误提示符合行为回归。
- [ ] 控制台没有新增 userscript error；站点自身既有错误单独记录。

5. 停止；不 push、不创建 tag、不触发 Nightly。
